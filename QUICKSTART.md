# 🚀 Quick Start Guide

Get up and running with AI Study Assistant in 5 minutes!

## ⚡ Fast Setup

### 1. Clone & Navigate
```bash
git clone https://github.com/yourusername/AI-Study-Assistant.git
cd AI-Study-Assistant
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure API Key
```bash
# Copy the example file
cp .env.example .env

# Edit .env and add your Groq API key
# GROQ_API_KEY=gsk_your_actual_key_here
```

### 4. Run the App
```bash
streamlit run main.py
```

That's it! The app will open at `http://localhost:8501` 🎉

## 🎯 First Steps

### Generate Your First Study Material

1. **Enter a Topic**
   - Type any subject (e.g., "Machine Learning")
   - Keep it focused for best results

2. **Click Generate**
   - Wait 2-5 seconds for AI to process
   - Study material will appear in tabs

3. **Explore Content**
   - **Explanation**: Read the overview
   - **Notes**: Review key points
   - **Quiz**: Test your knowledge

### Try These Features

#### 📊 View Analytics
- Click "Analytics" in sidebar
- See your study statistics
- Track your progress

#### 🔖 Save Bookmarks
- Click the bookmark button
- Access saved materials anytime
- Organize your favorites

#### 📥 Export Content
- Select format (Markdown/Text/JSON)
- Click Export button
- Download for offline study

#### 🌙 Toggle Theme
- Click theme button in sidebar
- Switch between dark/light mode
- Preference is saved

## 💡 Pro Tips

### Get Better Results
- ✅ Use specific topics: "Neural Networks" not "AI"
- ✅ Keep topics under 100 words
- ✅ Try different subjects to explore
- ✅ Review notes before taking quiz

### Maximize Learning
- 📚 Generate multiple related topics
- 🔖 Bookmark important materials
- 📊 Track your accuracy over time
- 📥 Export for offline review

### Troubleshooting
- ❌ **API Error**: Check your API key in .env
- ❌ **Slow Response**: Normal, LLM takes 2-5 seconds
- ❌ **Empty Result**: Try a different topic
- ❌ **Quiz Issues**: Refresh and try again
